# X-App-Lite v1.2 — GitHub Pages

Δωρεάν web εφαρμογή, χωρίς Node.js, Client ID, Client Secret ή API credits.

Ανέβασε **τα αρχεία μέσα στον φάκελο** στο κεντρικό επίπεδο του GitHub repository `CKMyApps/X-App-Lite`, ώστε το `index.html` να βρίσκεται δίπλα στο README. Έπειτα: Settings → Pages → main → /(root).

Η εφαρμογή διαθέτει ελληνικά/αγγλικά, εναλλαγή φωτεινού/σκοτεινού θέματος, προσχέδια, αγαπημένα προφίλ και φόρμα σύνταξης που ανοίγει την επίσημη δημοσίευση του X με έτοιμο κείμενο. Η τελική δημοσίευση γίνεται στο X από τον χρήστη.

**Δεν υπάρχει ενσωματωμένη σύνδεση λογαριασμού ή ανεξάρτητο χρονολόγιο.** Το επίσημο X ανοίγει ξεχωριστά και μπορεί να προβάλλει πολυμέσα και διαφημίσεις.

Μην ανεβάσεις `.env`, Client Secret ή άλλα κλειδιά στο δημόσιο GitHub. Δεν χρειάζονται για αυτή την έκδοση.
