# X-App-Lite v1.3 Clean

A lightweight bilingual (EN/EL) companion for X. No API keys, backend, or independent X timeline. Compose text and use the official X website to publish; search and favorite public profiles, store up to 30 drafts locally. The app never requests an X password.

## Deploy
Upload the **files inside this folder** to the root of `CKMyApps/X-App-Lite` (branch `main`); keep your existing `LICENSE` and `terms.html`. GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root). No custom domain needed.

No service worker is installed in this clean version to avoid stale cache. PWA installation depends on browser support. Existing service worker from older versions may need unregistering in browser site data.

Independent project; not affiliated with X Corp.
