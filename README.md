# X-App-Lite v1.3

Lightweight static companion for X (not an independent timeline client).

## Features
- Greek/English UI and dark/light mode
- Text composer with autosaved working draft and up to 30 separately saved drafts
- Favorites stored locally
- Search and opening posts on the official X website
- PWA manifest, install guidance, service worker and offline UI cache
- Own app icons based on user-provided AppIcon.jpg

## Publish
Upload **all files inside this folder** to the repository root in GitHub Pages, replacing older files. No `.env`, API keys, Node.js, OAuth or payment required. `icon.svg` is no longer used and can be removed.

## Limits
X timeline and actual posting open on x.com. No independent timeline rendering, direct publishing, or DMs. Local drafts stay in this browser unless storage is cleared. The X posting interface may count characters differently than this local editor.
