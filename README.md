# X-App-Lite
A Lightweight, Text-Focused Web Companion for X (Twitter)

X-App-Lite is a free, lightweight web application designed to offer a simpler, cleaner way to interact with X (formerly Twitter).

Built with HTML, CSS, and JavaScript, it focuses on text-based communication, fast loading, and minimal distractions.

No installation, additional account registration, or X Developer API access is required.

Features

Text-Only Composer – Write and prepare text posts in a clean interface.

Post to X – Open the official X publishing interface with your text already prepared.

Timeline Access – Quickly open your X timeline.

Search – Search public posts and user profiles.

Favorites – Save frequently visited X accounts for quick access.

Drafts – Save unfinished posts locally in your browser.

Dark & Light Modes – Choose your preferred appearance.

Multilingual Interface – English and Greek.

Responsive Design – Optimized for desktop computers, tablets, and smartphones.

Free to Use – No subscriptions or additional hosting services required.

How It Works

X-App-Lite works as a lightweight companion to the official X website.

Open the application in your web browser.

Write a text post using the built-in composer.

Select the publishing option to continue on X.

Sign in to your X account if required.

Review and publish your post.

You can also access your timeline, search for public content, and open your favorite profiles.

Important: X-App-Lite does not independently retrieve or display X timelines. Reading posts, viewing profiles, and publishing content take place through the official X website, where media and other standard X features may still appear.

Privacy

X-App-Lite does not request or store your X password, authentication credentials, or API tokens.

Drafts, favorites, and interface preferences are stored locally in your browser.

The application does not operate an independent user account system or collect personal information through its own backend.

When you open X, the official platform's privacy policy and terms apply.

Limitations

X-App-Lite is not a full replacement for the official X website.

No direct access to private X account data.

No independent timeline rendering.

No direct publishing through the X API.

No direct messaging functionality.

No built-in media uploading or playback.

Some actions require leaving X-App-Lite and opening X.
