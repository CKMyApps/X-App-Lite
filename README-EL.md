# X-App-Lite v1.3 Clean

Δίγλωσση (Ελληνικά/Αγγλικά) συνοδευτική εφαρμογή για το X. Χωρίς API ή server. Σύνταξη κειμένου και δημοσίευση στην επίσημη ιστοσελίδα X, αναζήτηση, αγαπημένα και έως 30 τοπικά προσχέδια. Δεν προβάλλει το προσωπικό χρονολόγιο μέσα στην εφαρμογή.

Ανεβάζεις **τα αρχεία** (όχι το ZIP) στον κεντρικό φάκελο του GitHub repository. Κρατάς τα υπάρχοντα `LICENSE` και `terms.html`. Το GitHub Pages πρέπει να δημοσιεύει το `main` από `/(root)`.

Η καθαρή έκδοση δεν εγκαθιστά service worker, ώστε να αποφευχθούν προβλήματα με παλιές cache. Παλαιότερο service worker μπορεί να χρειάζεται αφαίρεση από τα δεδομένα ιστοτόπου στον browser.
