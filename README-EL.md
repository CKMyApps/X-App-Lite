# X-App-Lite 1.3 — Οδηγίες

Ανεβάζεις **όλα** τα αρχεία του φακέλου στον κεντρικό φάκελο του GitHub repository `X-App-Lite`. Αντικαθιστάς τα παλιότερα. Δεν ανεβάζεις `.env`, κλειδιά ή tokens. Το παλιό `icon.svg` δεν χρειάζεται.

Νέα: εγκατάσταση ως PWA όπου υποστηρίζεται, οδηγίες εγκατάστασης, μέχρι 30 αποθηκευμένα προσχέδια, δίγλωσσο περιβάλλον, φωτεινό/σκοτεινό θέμα, νέο cache version και σταθερά εικονίδια PNG.

ΠΡΟΣΟΧΗ: Η ανάρτηση και το χρονολόγιο ανοίγουν στον επίσημο ιστότοπο X. Δεν γίνεται ανεξάρτητη εμφάνιση αναρτήσεων ή αυτόματη δημοσίευση. Τα προσχέδια αποθηκεύονται μόνο στη συγκεκριμένη συσκευή/browser και χάνονται αν διαγραφούν τα τοπικά δεδομένα.
